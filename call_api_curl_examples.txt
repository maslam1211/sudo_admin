SudoTag call API — curl (production host: https://sudotag.com)

1) Register intent (browser flow calls this; no secret header).
2) PBX POST /admin/api/call must send Authorization: Bearer <CALL_ROUTING_API_KEY> (same as sudo_admin/settings.py).

---

Register:
curl -sS -X POST "https://sudotag.com/admin/api/call/register" \
  -H "Content-Type: application/json" \
  -d '{"from":"9876543210","destination":"9123456789"}'

Webhook (Bearer must match CALL_ROUTING_API_KEY):
curl -sS -X POST "https://sudotag.com/admin/api/call" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SudoTag4455" \
  -d '{"did":"8049649451","from":"9876543210"}'

Windows CMD (one line each):
curl -sS -X POST "https://sudotag.com/admin/api/call/register" -H "Content-Type: application/json" -d "{\"from\":\"9876543210\",\"destination\":\"9123456789\"}"
curl -sS -X POST "https://sudotag.com/admin/api/call" -H "Content-Type: application/json" -H "Authorization: Bearer SudoTag4455" -d "{\"did\":\"8049649451\",\"from\":\"9876543210\"}"
